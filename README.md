# 🍕 Pizzeria Smart Pro - Gestionale Real-Time & Offline

Gestionale web completo multi-dispositivo per pizzeria:
- **Cameriere**: Presa comande, modifiche ingredienti (+/-), variazioni prezzi automatiche.
- **Capo Sala**: Griglia metrica 1m x 1m, drag & drop tavoli/zone, prenotazioni visive.
- **Pizzeria**: Doppio schermo Pre-Cottura (infornata) e Post-Cottura (a freddo), tracking consumi serata.
- **Cucina**: Comande calde, magazzino generale con tracciamento lotti e date di scadenza.
- **Asporto**: Cron Job differito per calcolo tempi di preparazione e rilascio sincronizzato.
- **Turni HR**: Fabbisogno manager, disponibilità dipendenti e Algoritmo di Fair Scheduling per i weekend.
- **Admin**: Cassa veloce (POS), scontrino trasparente, modifiche al menu.
